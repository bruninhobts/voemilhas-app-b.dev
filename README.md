## 🇧🇷 Português

> **Plataforma SaaS B2B para Emissão e Gestão de Passagens com Milhas**

Uma solução completa de ERP e CRM projetada especificamente para agências de viagens e emissores de passagens aéreas que operam no mercado de milhas. O sistema centraliza a operação, automatiza cotações e protege a margem de lucro.

### 🚀 Principais Funcionalidades
- **Controle de Margem**: Ajuste fino do preço do milheiro para Smiles, LATAM Pass e TudoAzul de forma simples.
- **Dashboard Financeiro**: Acompanhamento de vendas, faturamento, lucros e desempenho de vendedores em tempo real.
- **Acessos por Perfil (RBAC)**: Vendedores visualizam apenas seus próprios leads e pedidos, protegendo a base de dados comercial.
- **Fluxo de Emissão**: Pipeline visual completo desde a cotação inicial até o envio do bilhete gerado em PDF.

### 🛠️ Tecnologias
- **Frontend**: React.js, TypeScript, Vite, Tailwind CSS.
- **Backend & Banco**: Node.js, PostgreSQL, Supabase/Firebase.
- **Integrações**: APIs de cotação aérea, gateways de pagamento (Pix/Mercado Pago).

## 🇺🇸 English

> **B2B SaaS Platform for Miles Flight Booking & Operations**

A complete ERP/CRM tool built for travel agencies issuing airline tickets with miles. It centralizes operations, automates quotes, and protects profit margins.

### 🚀 Key Features
- **Margin & Markup Control**: Fine-tune pricing for Smiles, LATAM Pass, and TudoAzul in a few clicks.
- **Financial Dashboard**: Real-time sales, revenue, profit margins, and sales rep performance metrics.
- **Role-Based Access Control**: Restrict sellers to view only their own customers and orders.
- **Ticketing Workflow**: Visual progress pipeline from quoting to PDF receipt delivery.

### 🛠️ Tech Stack
- **Frontend**: React.js, TypeScript, Vite, Tailwind CSS.
- **Backend & Database**: Node.js, PostgreSQL, Supabase/Firebase.
- **Integrations**: Flight quoting APIs, payment gateways (Pix/Mercado Pago).
